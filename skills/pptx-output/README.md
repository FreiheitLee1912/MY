# pptx-output 技能研究

研究 PowerPoint (`.pptx`) 文件的生成方案与工具。

## 目录结构

| 目录 | 用途 |
|------|------|
| `uploads/` | **您上传的原始文件放这里**(Gantt、素材、参考 pptx 等) |
| `references/` | 研究笔记、库用法、方案对比 |
| `scripts/` | 可运行的生成脚本 |
| `templates/` | 模板文件(pptx 模板、布局说明) |
| `examples/` | 示例输出 |
