# ACN風スライド

DAICEL版「JIRA登録タイミング」スライドを、Accenture (ACN) のハウススタイルに
作り直したものです。

## 生成方法

```bash
pip install python-pptx
python build_acn_slide.py <Acc_PPT_IMP_StarterPack....potx> [出力先.pptx]
```

スターターパック (`.potx`) からデモスライドを取り除いてマスター／レイアウトだけを
残し、その上にスライドを組み立てます。`>` マークやフッターはマスターから継承される
ため、スクリプト側では描画していません。

## デザインの対応関係

| 要素 | DAICEL版 | ACN版 |
|---|---|---|
| 基調色 | コーポレートブルー | Accenture Purple `A100FF` / `7500C0` / `460073` |
| 見出し | ゴシック太字＋上罫線 | Arial Black 27pt、罫線なし（左上ベタ置き） |
| 補助色 | グレー・グリーン | ウォームグレー `E6E6DC` / `96968C` |
| 版面 | 全幅 | 左右マージン 0.42"、テキスト幅 12.50"（ACNグリッド） |
| フッター | ロゴ＋ページ番号 | マスターの `>` マーク＋ページ番号 |

ライフサイクルの色分けは、元スライドの「グレー＝対象外 / ブルー＝SOP前 / グリーン＝
SOP後」を、ACNのパープル・ランプ（淡いパープル＝SOP前、ベタのパープル＝SOP後、
ウォームグレー＝対象外）に置き換えています。

## 構成

- 見出し（結論）＋サブ見出し
- 登録判断バンド … INF／イニシそれぞれのトリガー定義
- プロジェクトライフサイクル … 9フェーズのシェブロン、SOPを破線で区切り
- スイムレーン … INF／イニシ別に「個別管理 → JIRAで管理 → PCR都度起票」
- 未決事項
- So What（結論バンド）

## 注意

生成物の `.pptx` は Accenture のテンプレート（マスター・テーマ・ロゴ）を含むため、
このリポジトリにはコミットしていません（`.gitignore` で除外）。
配布・公開時はテンプレートの利用条件を確認してください。
